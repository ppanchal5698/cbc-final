# Frame Depth by Wall Type

Frame **throat / depth** is derived from the wall construction. Five standard throat sizes
cover most work — offer them as a pick-list plus a CUSTOM manual-entry option.

| Wall type | Throat / depth | Note |
|---|---|---|
| Half-inch drywall | **5-5/8"** | Common at McDonald's |
| Masonry | **5-3/4"** | |
| Drywall | **5-7/8"** | |
| Wood-frame variant | **7-3/4"** | |
| 6" metal stud + 5/8" drywall | **8-1/4"** | |

- **CUSTOM** manual entry is allowed — practical ceiling is about **10 sizes**.
- **Adjustable frames** also exist and are a valid answer when the wall type is unclear.

If the wall type cannot be read off the drawing, do **not** guess a depth — flag the opening
for estimator review (see [[manual_cutoff]] and the accuracy-trust rule).
